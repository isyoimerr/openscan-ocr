# Seguridad y privacidad

Este repositorio es un **prototipo**, no un sistema certificado para documentos sensibles.

- Los ejemplos publicados son sintéticos y no contienen información personal real.
- Las subidas se procesan en memoria y esta versión no tiene base de datos de documentos.
- En un despliegue público, los documentos se transfieren al servidor que aloja Streamlit.
- Al activar Gemini, el contenido se envía a un servicio externo de Google; revisa sus términos y políticas.
- La API se configura con `GEMINI_API_KEY` y nunca debe publicarse en Git.
- Los límites de tamaño y páginas son controles básicos, no un aislamiento completo para archivos maliciosos.

Para reportar una vulnerabilidad, evita publicar los detalles explotables en un issue público; contacta al mantenedor mediante los canales de su perfil de GitHub.
