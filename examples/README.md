# Ejemplos para probar OpenScan

Todos los archivos de esta carpeta son **ficticios** y no tienen validez comercial.

- `factura_01_limpia.png`: factura de demostracion limpia.
- `factura_02_inclinada.png`: la misma factura con inclinacion y desenfoque.
- `factura_03_ruido.png`: la misma factura con sombras y ruido.
- `factura_referencia.txt`: transcripcion correcta comun a las tres imagenes.
- `recibo_demo.png` y `recibo_referencia.txt`: otro documento de prueba.
- `facturas_demo_3paginas.pdf`: imagenes reunidas en un PDF sin capa de texto.

Puedes usar estos archivos en la aplicacion, el cuaderno publico y el benchmark local.
